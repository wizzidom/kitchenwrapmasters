Which Fridge Is This For?

This kit is sized for a double-door fridge — the configuration where the freezer compartment sits above or below the main fridge section, with one door for each compartment stacked vertically.

If you have a side-by-side fridge (two doors sitting side by side), see our DIY Side-by-Side Fridge Bundle instead.
